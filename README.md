# board-entry

調整提案ボードの入口ページです。アプリ(Google Apps Script の Web アプリ)の画面を受け取って、このページとして表示するだけです。

- データ・アプリの URL はこのリポジトリに含みません。アプリの番号は、送られてきた URL の `#` の後ろ(`#d=…`)で受け取ります(`#` の後ろはサーバに送られません)。
- 画面の受け取りと書き込みは、Google のログイン情報(Cookie)を付けずに行います。そのため、iPhone の Safari などが Google にログインしていても開けます。受け取れなかったときは、アプリをこのページの中に埋め込んで開きます。
- データは Google からブラウザに直接届きます。このページ(GitHub)を通りません。
- お名前を選ぶ画面では、お名前ごとの画面を先に受け取っておき、押したらすぐ表示します(受け渡しはそのタブの中だけで行い、表示したらすぐ消します)。
- 元のファイルは非公開のリポジトリにあります(ここは写し)。
